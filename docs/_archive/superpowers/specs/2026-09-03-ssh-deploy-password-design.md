# SSH 首次部署密码设计

**日期：** 2026-09-03

## 目标

允许用户为 SSH Host 保存首次部署公钥所需的登录密码，部署时自动完成一次密码提示输入，部署成功后继续使用现有免密 SSH 流程。

## 凭据存储

- 使用 Electron `safeStorage` 加密密码，凭据文件只保存密文，不保存明文密码。
- 凭据按 `hostId` 隔离，Host 列表和页面只显示“已保存/未设置”。
- safeStorage 不可用、解密失败或文件损坏时返回稳定错误，不降级到明文。
- 提供保存、删除、查询状态三个 typed IPC 操作。
- 密码不进入 renderer 持久状态、SSH 列表缓存、日志、audit、终端输出或命令行参数。

## 部署流程

- 点击“部署公钥”前仍执行 Host 查找、指纹扫描和 known_hosts 信任校验。
- 主进程从凭据服务读取该 Host 密码，将其作为进程内存中的短生命周期值交给 SSH PTY adapter。
- PTY 仅在检测到标准 SSH 密码提示时自动发送密码加换行；密码发送后立即清除引用。
- 进程退出、会话关闭、部署失败或超时都会清理待发送密码。
- 没有已保存密码时保持现有交互式部署行为，用户可在 xterm 中手动输入。
- 不使用 `sshpass`、环境变量、shell 拼接或远程命令参数传递密码。

## UI

- SSH Host 详情显示凭据状态，不显示密码内容。
- 增加“保存部署密码”“更新部署密码”“删除已保存密码”操作。
- 保存密码使用密码输入框，空密码拒绝提交。
- 部署按钮在 Host 已受信且公钥存在时可用；密码保存只是自动输入便利，不改变信任门禁。
- 成功保存、删除和部署后显示明确状态；底层错误不回显敏感内容。

## 安全边界

- renderer 只发送已验证的 `hostId` 和密码设置请求；主进程重新校验 Host ID。
- 凭据服务不接受任意文件路径、命令、Host alias 或终端参数。
- IPC 继续执行 sender guard，密码字段限制为有限 UTF-8 长度并拒绝 NUL。
- 只有部署流程可读取密码；列表、连接、外部终端和诊断流程不能读取凭据。

## 测试与验收

- 凭据服务测试 safeStorage 不可用、加密/解密、保存/读取/删除、损坏密文和 Host 隔离。
- PTY 测试密码提示自动发送一次、非提示不发送、退出清理和密码不进入输出回调。
- service/IPC 测试 Host 门禁、凭据读取和参数校验。
- renderer 测试保存/删除状态、密码框和部署按钮行为。
- 全量测试、typecheck、build、`git diff --check` 通过；不自动连接远端。
