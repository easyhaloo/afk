# SSH 主机详情操作按钮优化设计

## 目标

在不改变 SSH 主机行为、IPC 调用和权限判断的前提下，优化详情区域的操作按钮层级，让“连接”成为唯一明确的主要操作，降低危险操作误触，并保持现有键盘可访问性与响应式布局。

## 范围

- 优化详情区域的连接、终端选择、测试免密、部署公钥、信任指纹和删除主机按钮。
- 保留现有按钮文案、图标、禁用条件、加载状态、点击回调和确认行为。
- 不修改主机列表、添加主机弹窗、部署密码面板及其按钮的业务行为；统一按钮基础视觉可复用到这些区域。

## 设计

- `primary` 仅用于当前上下文的主动作：可连接主机显示“连接”，未信任主机显示“信任此指纹”。
- `secondary` 使用轻量描边和柔和 hover，承载“测试免密”“部署公钥”等辅助动作。
- 终端选择器与连接按钮保持同一行，选择器承担次级视觉，连接按钮占据更明显的宽度。
- `danger` 使用低饱和浅红背景与文字；删除主机从普通按钮降为低干扰操作，但仍保留明确文本和可访问名称。
- 统一按钮高度、圆角、间距、focus-visible 状态和 disabled 状态；窄屏时动作组继续整体换行，不出现横向溢出。
- 暗色 graphite 主题沿用同等层级，不引入新的颜色 token。

## 验收标准

1. 详情操作区可直观看出“连接”是主操作，辅助操作不会与其争夺视觉权重。
2. 危险操作有独立危险样式，且不会因为 hover 或 focus 丢失可读性。
3. 现有 SSH 页面测试继续通过，并补充按钮层级与 class 结构的聚焦测试。
4. `desktop-client` 独立 typecheck、build 和相关测试通过。
