# SSH 主机编辑能力设计

## 目标

为 SSH 主机页面增加 AFK 管理主机的编辑能力：用户双击主机行打开编辑弹框，修改后原子更新 AFK SSH 配置。

## 范围与交互

- 仅 `source === "managed"` 的主机支持编辑；系统配置主机保持只读。
- 双击 AFK 管理主机行打开编辑弹框；系统配置主机双击不触发编辑。
- 编辑弹框复用添加主机表单并回填别名、地址、端口、用户、密钥、跳板机和远程工作区。
- 编辑模式标题为“编辑 SSH 主机”，提交按钮为“保存修改”。
- 编辑模式不显示新增时的部署密码字段，不改变已有部署密码。
- 保存成功后关闭弹框、刷新列表并保持编辑主机选中。

## 架构与数据流

- shared contract 新增带 `hostId` 的更新请求和 preload/API `update` 方法。
- IPC handler 校验发送方、主机 ID 和主机输入；service 再次确认目标主机来源为 managed，防止绕过 UI 修改系统配置。
- SSH service 调用 config adapter 原子更新配置块；别名变化时从旧别名块迁移到新别名块，避免重复配置。
- 更新流程不读取或改写凭据服务，避免编辑主机配置时意外暴露或清除部署密码。
- 更新后使 SSH 列表缓存失效，后续连接、测试和部署使用新配置。

## 错误处理与安全

- 输入复用现有 SSH 主机校验；重复别名、非法路径和非法跳板机参数返回可展示错误。
- 配置写入失败时不更新列表，不删除旧配置或旧凭据。
- 不允许通过更新接口修改非 managed 主机。

## 测试

- adapter：同别名更新、别名迁移、旧配置块保留边界和写入失败保护。
- service：managed 来源校验、更新后缓存失效、凭据处理。
- IPC contract：preload 暴露 update 且参数受校验。
- page：双击 managed 行打开并回填编辑弹框，双击 system 行不打开，提交调用 update 并刷新。
