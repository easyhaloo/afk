# Backlog 开始执行按钮尺寸优化

## 目标

保留 Provider Backlog 卡片右上角的圆形播放按钮，将其从当前的 28px 缩小为 22px，降低标题行中的视觉重量，同时不改变执行行为。

## 设计

- `.backlog-run-button` 的宽度、高度和 flex 固定基准统一为 22px。
- 保留现有圆形靛蓝背景、白色播放图标、阴影、hover、focus-visible 和 disabled 状态。
- 保留 `aria-label`、`title`、点击事件阻止冒泡、禁用条件和 Backlog 执行 IPC 调用。
- 不新增业务逻辑，不调整卡片其余排版。

## 验收标准

1. 开始执行按钮视觉尺寸为 22px，并且标题行不会保留 28px 的固定占位。
2. 按钮仍显示圆形播放语义，现有辅助文本和可访问名称保持不变。
3. 相关 Backlog 页面测试通过，运行行为不变。
