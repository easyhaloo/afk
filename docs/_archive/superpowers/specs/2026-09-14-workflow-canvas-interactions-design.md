# 工作流画布交互设计

## 目标

让工作流编辑器具备完整的画布交互：滚轮缩放、全部节点拖拽，以及可区分的步骤新增入口。

## 交互设计

- 画布在鼠标或触控板滚轮事件下，以指针所在位置为缩放中心。
- 缩放范围保持为 70%–135%，右下角缩放按钮继续可用。
- 开始节点、内置模板节点和自定义节点均可拖动。
- 自定义节点位置继续写入工作流草稿；只读内置节点的位置保存在当前编辑会话中，切换模板后重置。
- 画布空白区域继续用于平移，节点按下优先进入节点拖动。
- 右上角只保留一个 `+` 添加入口，符合桌面端图标优先规范。
- 点击 `+` 后展示步骤类型菜单，使用图标、名称和简短说明区分 Agent 与 QA。
- 点击菜单外或按 Escape 关闭菜单；选择类型后关闭菜单并创建对应节点。

## 视觉设计

- 添加按钮沿用工作流工具栏的全局按钮语言。
- Agent 使用绿色语义图标，QA 使用琥珀色语义图标。
- 菜单作为轻量浮层，不改变画布布局，也不持续占用 Header 宽度。

## 验收标准

- 滚轮操作会改变画布缩放比例，并保持指针下的世界坐标稳定。
- 任意内置节点拖动后，其屏幕位置发生变化。
- 自定义节点拖动仍会更新可保存坐标。
- Header 中只有一个添加按钮，并可展开 Agent/QA 两个清晰选项。
- 现有画布平移、自动布局、底部填充和完整宽度行为不回归。
