# Backlog Provider 选择器样式对齐设计

## 目标

将 Provider Backlog 页头的“自动探测”选择器与工具栏的“全部状态”选择器统一为相同的触发器布局，同时保持现有选择、加载和下拉菜单行为不变。

## 当前问题

“自动探测”选择器显式使用 `SelectMenu` 的 `center` 触发器布局，文字与箭头作为一组居中；“全部状态”使用默认布局，文字靠左、箭头靠右。两个同类下拉控件因此呈现不同的视觉结构。

## 选定设计

- 移除 Provider 选择器的 `triggerLayout="center"` 配置，使其使用 `SelectMenu` 默认布局。
- “自动探测”文字靠左，下拉箭头靠右，与“全部状态”保持一致。
- 保留 Provider 选择器现有宽度、控件高度、边框、圆角、颜色和页头位置。
- 保留 `SelectMenu` 的居中布局能力，避免影响可能存在的其他调用方或扩大改动范围。
- 不修改下拉选项、数据加载、Provider 切换及无障碍属性。

## 验收标准

1. “自动探测”和“全部状态”的触发器都采用文字靠左、箭头靠右的布局。
2. Provider 选择器仍位于新增按钮左侧，尺寸与间距不变。
3. GitHub、GitLab 与自动探测选项仍可正常切换。
4. 状态筛选器及其他 `SelectMenu` 调用方行为不变。
5. 桌面端相关单元测试、类型检查和构建通过。
