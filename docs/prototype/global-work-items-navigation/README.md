# AFK Control 全局工作项导航原型

该原型验证新的菜单信息架构和工作项执行流程：

- 菜单始终保持单层，只通过 `工作 / 自动化 / 资源 / 系统` 分组。
- 工作项是独立业务对象，不属于工作区或代码仓库。
- GitHub、GitLab Issue 是工作项的外部来源，一个工作项可以关联多个来源。
- 代码仓库是可选资源，一个工作项可以关联零个、一个或多个仓库。
- 执行时创建 `~/.loop-workspace/<task-id>/`，并在任务目录中分别检出关联仓库。
- “项目 Backlog”从菜单中移除，规划和运行能力分别归入“工作项”和“运行中心”。

## 查看方式

```bash
open docs/prototype/global-work-items-navigation/index.html
```

## 推荐评审路径

1. 查看侧边栏的单层分组结构。
2. 点击“支付链路重构与灰度切换”。
3. 查看一个工作项关联多个外部 Issue 和多个代码仓库。
4. 点击“开始执行”。
5. 确认隔离任务目录与三个仓库检出位置。
6. 点击“创建运行”，自动进入“运行中心”。
7. 点击“代码仓库”，确认仓库仅作为全局资源目录存在。

## 原型范围

这是产品交互原型，不包含真实 Provider 调用、持久化或任务执行。
