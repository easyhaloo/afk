# SSH xterm Terminal Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将 AFK Desktop 的 SSH `<pre>` 伪终端替换为 xterm.js，使 ANSI 渲染、中文组合输入、粘贴、复制和 PTY 尺寸同步符合真实终端行为。

**Architecture:** `TerminalSheet` 保留浮层外壳和 tmux 只读模式；新增 `SshTerminalView` 持有 xterm/fit 生命周期。无 DOM 的输出增量、按键决策和 controller 编排放入独立纯模块并通过依赖注入测试；renderer 只调用现有 typed IPC，主进程 SSH/clipboard 安全边界不放宽。

**Tech Stack:** Electron 35、React 19、TypeScript、Vitest、`@xterm/xterm` 6.0.0、`@xterm/addon-fit` 0.11.0、node-pty、现有 AFK Desktop SSH IPC。

- [ ] **Step 5: 实现纯模型**

实现以下公开类型和函数：

```ts
export type TerminalPlatform = "mac" | "other";
export type XtermKeyAction = "copy" | "native-paste" | "terminal";

export function terminalOutputUpdate(previous: string, next: string) {
  if (next === previous) return { reset: false, data: "" };
  if (next.startsWith(previous)) return { reset: false, data: next.slice(previous.length) };
  return { reset: true, data: next };
}

export function xtermKeyAction(input: {
  platform: TerminalPlatform;
  key: string;
  metaKey: boolean;
  ctrlKey: boolean;
  shiftKey: boolean;
  hasSelection: boolean;
}): XtermKeyAction {
  const key = input.key.toLowerCase();
  if (input.platform === "mac" && input.metaKey && key === "c" && input.hasSelection) return "copy";
  if (input.platform === "other" && input.ctrlKey && key === "c" && input.hasSelection) return "copy";
  if (input.platform === "other" && input.ctrlKey && input.shiftKey && key === "v") return "native-paste";
  if (input.platform === "mac" && input.metaKey && key === "v") return "native-paste";
  return "terminal";
}
```

`Ctrl+Shift+C` 在非 macOS 且存在选区时同样返回 `copy`。

- [ ] **Step 4: 实现 controller**

导出 `createSshTerminalController({ terminal, platform, input, resize, copy, reportError })`，返回：

```ts
{
  syncOutput(nextOutput: string): void;
  dispose(): void;
}
```

实现约束：

- `onData` 的 payload 原样交给 `input`，不得拆字符。
- `syncOutput` 使用 `terminalOutputUpdate`；replacement 先 `reset()` 再 `write()`。
- custom key handler 的 `copy` 动作调用 `terminal.getSelection()` 和 `copy()`，返回 `false` 阻止 xterm 把按键发送远端。
- `native-paste` 返回 `true`，让 xterm textarea 接管 paste。
- `terminal` 返回 `true`，让 xterm 生成控制序列。
- `onResize` 按 `cols:rows` 去重，再调用 `resize`。
- `input`、`resize`、`copy` 的 Promise rejection 统一交给 `reportError`，不得产生未处理 rejection。
- `dispose()` 清理 controller 创建的所有 disposable。
