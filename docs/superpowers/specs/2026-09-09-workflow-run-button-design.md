# Backlog 开始执行按钮设计

## 目标

将 Provider Backlog 卡片中的开始执行入口移动到卡片右上角并优化为圆形播放按钮，使其更符合“启动运行”的动作语义，同时保持现有执行逻辑不变。

## 设计

- 在每个 Provider Backlog 卡片标题行的右侧放置圆形播放按钮。
- 使用 Backlog 页面现有靛蓝强调色作为按钮背景，白色播放图标作为前景。
- 按钮尺寸保持紧凑但满足可点击区域，使用圆形外观与轻微阴影突出主动作。
- 添加 `aria-label="开始执行"` 与 `title="开始执行"`，在无文字按钮的情况下保留可访问性和悬停提示。
- 卡片标题、编号、标签和详情抽屉继续保留；开始执行按钮沿用 backlog 执行 IPC 和运行状态回调，不新增业务逻辑。
- 按钮点击阻止冒泡，避免同时打开卡片详情。
- 在窄屏下继续随卡片标题行自然收缩，不改变页面的整体响应式结构。

## 验收标准

1. Provider Backlog 卡片右上角显示圆形靛蓝播放按钮，不显示“开始执行”文字。
2. 按钮具备可访问名称“开始执行”，并保留现有执行行为。
3. 运行中、启动中、失败重试和非 ready 状态继续正确反映并禁用按钮。
4. 桌面端类型检查、相关测试和构建通过。
