# Backlog Provider 选择器布局优化设计

## 目标

优化 Provider Backlog 页头的“自动探测”选择器，使其与相邻的独立加号按钮保持协调，同时继续复用通用 `SelectMenu` 组件。

## 当前问题

Provider 选择器使用三列网格和左侧伪占位抵消右侧箭头，令文字在按钮几何中心对齐。该做法使文字与箭头视觉割裂，中部留白不自然，且页面样式直接覆盖通用组件内部结构。

## 选定设计

- 保留选择器和加号按钮为两个独立控件，不组成连体控件。
- “自动探测”文字与下拉箭头作为一个视觉组整体居中。
- Provider 选择器宽度从 120px 收紧到 112px，高度继续与 30px 加号按钮一致。
- 选择器与加号按钮保持现有紧凑间距。
- `SelectMenu` 增加显式的触发器布局变体，由组件输出稳定 class；页面不再通过伪元素模拟居中。
- Provider 使用居中变体；状态筛选与弹窗执行模式继续使用默认的两端对齐布局。
- 下拉菜单选项保持左对齐，交互和无障碍行为不变。

## 验收标准

1. Provider 触发器中文字和箭头相邻，并作为整体在按钮内居中。
2. Provider 选择器宽度为 112px，与加号按钮同高且保持独立。
3. Provider 触发器不再依赖 `::before` 伪占位或三列网格。
4. 状态筛选与弹窗选择器仍为文字左侧、箭头右侧。
5. 菜单选项继续左对齐。
6. 所有现有选择、筛选和键盘交互保持正常。
