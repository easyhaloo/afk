# Backlog 工作项状态标签设计

## 目标

优化 Provider Backlog 页面中每条工作项的状态信息展示，并修正顶部 Provider 选择器的文案对齐：

- 将当前“状态 · 执行模式”纯文本改为并排的双标签。
- 将顶部“自动探测”当前选中文案真正居中，右侧下拉箭头保持原位。
- 不改变筛选、执行、详情打开、标签管理等现有行为。

## 视觉设计

### 状态标签

- 使用圆角胶囊标签，包含一个小圆点和本地化状态文案。
- 标签高度约 22px，使用紧凑字号和 6px 左右的内部元素间距。
- 状态颜色沿用桌面端现有低饱和语义色：
  - `ready`：中性灰绿色。
  - `in_progress`、`rework`：运行绿色。
  - `verification`、`merge_ready`：验证青绿色。
  - `blocked`：注意琥珀色。
  - `done`：完成绿色。

### 执行模式标签

- “AFK 自动”和“HITL 人工”使用中性描边胶囊标签。
- 不显示状态圆点，视觉优先级低于状态标签。
- 与状态标签并排展示，间距约 6px。

### Provider 选择器

- 仅顶部 Provider 选择器的当前选中文案居中。
- 下拉箭头仍固定在右侧，居中位置不受箭头宽度影响。
- 展开后的菜单选项继续左对齐。
- 状态筛选和弹窗中的其他 SelectMenu 不受影响。

## 交互与无障碍

- 状态与执行模式标签只展示信息，不新增点击行为。
- 保留工作项卡片整体点击、执行按钮、标签编辑行为。
- Provider 选择器继续使用现有无障碍名称、键盘和展开交互。

## 验收标准

1. 每条工作项以两个并排标签展示状态和执行模式，不再显示中点分隔纯文本。
2. 状态标签包含圆点，并按状态类别应用对应语义色。
3. 执行模式标签使用中性描边样式。
4. “自动探测”文案在 Provider 选择器按钮几何中心对齐，箭头保持右侧。
5. Provider 菜单选项、状态筛选和弹窗选择器保持原有对齐方式。
6. Backlog 页面现有筛选、执行、详情与标签操作不发生行为回归。
