# 运行中心工作区式 UI 设计

## 背景

运行中心当前已经能够展示真实运行、历史记录、任务空间和执行阶段，但现有界面容易被理解为数据看板：统计卡片过重、运行信息层级分散、队列和看板的任务来源不够直观。

本次改造将运行中心调整为 Codex 桌面端风格的“工作区 + 运行列表 + 详情 Inspector”，重点是快速扫描运行状态和进入具体执行上下文，而不是展示汇总指标。

## 目标

- 默认进入紧凑的连续运行流，优先呈现当前需要关注的运行。
- 队列记录统一显示来源图标、仓库名、工作项编号、阶段、时间和详情入口。
- 点击记录后在右侧 Inspector 查看运行上下文，不离开运行中心。
- 看板作为辅助视图保留，用于按阶段扫描执行中、已完成、待处理和失败。
- 视觉遵循 Codex 桌面端：中性灰白画布、细边框、紧凑间距、克制状态色和图标优先。

## 非目标

- 本次不改变运行数据模型、IPC 合约或运行生命周期。
- 本次不新增全局刷新机制。
- 本次不实现完整日志编辑器；日志入口只保留现有导航能力。
- 本次不将运行中心改造成指标监控大屏。

## 信息架构

### 页面 Header

- 面包屑：`AFK › 运行中心`。
- 视图切换：`队列`、`看板`。
- 右侧只保留上下文菜单和时间范围/筛选入口，不放全局刷新按钮。
- 页面标题为“运行中心”，副文案说明可以查看状态、处理异常和打开执行详情。

### 队列视图（默认）

队列使用连续列表而不是卡片墙，不使用“执行中 / 待处理 / 已完成 / 失败”等大段文案分隔标题。运行按执行中、待执行、已完成、待处理的稳定顺序排列；每条记录左侧的细轨道、状态图标和克制的状态色承担分辨职责。失败记录与待确认记录共处待处理阶段，但使用独立的失败图标和弱红色语义。

每条记录包含：

- GitHub 或 GitLab 图标。
- 仓库名，例如 `easyhaloo/afk`。
- 工作项编号，例如 `#144`。
- 工作项标题。
- 当前阶段和运行状态。
- 开始时间或运行时长。
- 详情入口。

没有运行时使用轻量空状态，不展示大型占位卡片或空分组标题。

### 看板视图

看板保留四个阶段列：

- 执行中
- 已完成
- 待处理
- 失败

看板列头只显示状态图标和数量，以悬浮提示与无障碍标签提供状态名称；卡片与队列使用相同的运行来源组件和状态语义。看板不显示顶部统计卡片，避免恢复数据看板风格。

### Inspector

右侧 Inspector 固定展示当前选中的运行：

- 来源图标、仓库名和工作项编号。
- 当前运行状态。
- 当前阶段、运行时长、任务空间和 Agent。
- 阶段时间线：准备运行、拉取工作项、执行阶段、验证并回写。
- 操作：打开详情、查看日志、关闭 Inspector。

Inspector 在没有选中记录时可以折叠；选中队列或看板记录时保持上下文同步。

## 视觉规范

- 画布使用 Codex 桌面端的浅灰背景和白色内容区。
- 侧栏沿用现有导航尺寸、圆角和灰色选中态。
- 主要交互焦点使用 Codex 紫色；运行成功使用低饱和绿色；失败使用弱红色；待处理使用琥珀色。
- 边框优先于阴影；仅 Inspector 使用轻量浮层阴影。
- 运行来源使用图标 + 仓库名 + 编号，禁止继续展示 `github:owner/repo #id` 形式的长前缀文本。
- 新建运行入口遵循桌面端规范，只显示 `+` 图标并提供无障碍名称。
- 列表标题和阶段信息允许省略，但不得逐字竖排；窄宽度下使用省略号。

## 交互

- 队列/看板切换不丢失当前选中运行。
- Inspector 默认收起；点击队列或看板记录后展开、更新内容并高亮当前记录。
- 关闭 Inspector 后，主列表获得更多空间；再次点击记录重新打开。
- GitHub/GitLab 图标提供准确的无障碍标签和悬浮提示。
- 项目筛选、状态筛选和时间范围作为局部上下文控件，不影响全局导航。
- 新建运行打开现有创建流程；本次不改变其业务行为。

## 实现边界

- React 组件只负责渲染和交互状态，不直接访问 Node/Electron 或本地文件。
- 运行来源展示数据由现有 Snapshot / WorkItemRun DTO 提供；如 DTO 缺少 provider 字段，使用适配层归一化，不在组件内解析长字符串。
- GitHub/GitLab 图标作为纯 UI 资源放在渲染层，不引入新的运行时网络依赖。
- 队列分组、排序和状态映射保持纯函数，新增或调整时配套测试。

## 验收标准

- 打开运行中心默认看到 Codex 风格队列，而不是统计仪表盘。
- 队列和看板都能显示 GitHub/GitLab 来源图标、仓库名和工作项编号。
- 任何一条运行记录都能在不离开页面的情况下打开右侧 Inspector。
- Inspector 能展示真实任务空间、运行阶段和 Agent 信息。
- 空状态、失败记录和长仓库名在视觉上可读且不发生竖排；状态不依赖文案分隔标题。
- 桌面包独立通过 typecheck、build 和测试检查。
